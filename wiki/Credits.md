# Credits

## custom:button-card

Button Builder is a visual configuration tool for
[`custom:button-card`](https://github.com/custom-cards/button-card), the
Home Assistant Lovelace card created by
[RomRider](https://github.com/RomRider).

The expressive configuration system provided by button-card—including its
state styling, layouts, actions, templates, and custom CSS support—is what makes
Button Builder possible. Thank you to RomRider and every button-card
contributor for creating and maintaining it.

Button Builder is an independent project and is not part of or officially
affiliated with the button-card project.
