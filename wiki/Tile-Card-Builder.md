# Tile Card Builder

Tile Card Builder is not included in Button Builder v3.

The Tile Card builder, Bubble Card builder, and other builders are planned as
separate Home Assistant integrations. Splitting them allows each builder to
have its own installation, release schedule, testing, and documentation.

Existing Tile Card YAML already used on a dashboard is not changed by upgrading
Button Builder. Only the visual editor was removed from this integration.

For current Tile card configuration options, see the
[Home Assistant Tile card documentation](https://www.home-assistant.io/dashboards/tile/).
